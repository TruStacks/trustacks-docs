# Self-hosted quickstart (not currently available)

The one-command install that brought the whole TruStacks platform up on a
laptop is not currently available. The control plane now needs a Postgres
database that the installer does not provide, so the installer does not
produce a working platform. Please don't use it.

<Callout type="info">
  **Where to go instead.**
  - **Using TruStacks:** follow the [Quickstart](/getting-started/hosted-quickstart).
    You use the hosted service and install only the runner in your cluster.
  - **Contributing to TruStacks:** follow [Local development](/contributing/local-dev)
    to build and run the full platform from source on k3d.
</Callout>
