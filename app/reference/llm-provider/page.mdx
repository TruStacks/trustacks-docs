# LLM provider (BYO key)

The agents run on Claude. You bring the API key, so model usage is billed to
your own account with Anthropic or OpenRouter. Set it under
**Settings** in the sidebar (`#/settings/llm`).

<Callout type="info">
  **Beta: the model is on us.** In the Beta program, TruStacks gives you an
  Anthropic API key at no charge, so you don't need your own to start. We send
  it to you when your workspace is set up; paste it under **Settings** like
  any other key. It stops working when the Beta ends. Before then, replace it
  with your own Anthropic or OpenRouter key on the same screen, and the agents
  carry on without a gap.
</Callout>

## Providers

| Provider | Key looks like | Model |
|---|---|---|
| **Anthropic** | `sk-ant-…` | Runner default. Optional override, for pinning during a Claude model rollover. |
| **OpenRouter** | `sk-or-v1-…` | Required, and must start with `anthropic/` (for example `anthropic/claude-sonnet-4-5`). |

Both run Claude Sonnet 4.5 or later. The choice is about who bills you, not
which model runs.

<Callout type="info">
  **There is no model picker, by design.** The agents and their prompts are
  tuned and tested only on Claude; other models are not supported.
  OpenRouter models that do not start with `anthropic/` are refused.
</Callout>

## What happens when you save

1. **Shape check.** The key and model are checked before anything else; a
   non-Anthropic OpenRouter model is rejected here.
2. **Held for your runner.** The control plane writes the key to a
   single-use secret in TruStacks' secret store that expires after two
   hours. It is never written to the TruStacks database.
3. **Sealed delivery.** When your runner collects the key, it is sealed to
   that runner's public key. The stored copy is deleted once the runner
   reports back, after it has written its Secret and tested the key.
4. **Runner writes it.** Your runner unseals it and writes the Kubernetes
   Secret `trustacks-runner-llm` in its own namespace.
5. **Live test call.** The runner makes a one-token request to the provider
   to prove the key works.

The control plane records the outcome of that check, but the Settings banner
doesn't show it yet: it reads *configured* as soon as you save. Your first
agent run is the confirmation; see [Troubleshooting](#troubleshooting).

The page shows only the first six characters of the key afterward. To
rotate, save a new key the same way.

## Where your key goes

| Place | Holds the key? |
|---|---|
| TruStacks database | No. Only the provider, the model override, the first six characters, and status. |
| TruStacks secret store | Up to two hours: deleted once your runner reports back, or when it expires |
| Your cluster | Yes, in the Secret `trustacks-runner-llm` in the runner's namespace |
| Your LLM provider | Receives it on every call, as usual |

## What the provider sees

Every agent call goes from your runner directly to Anthropic or OpenRouter.
Those calls include the instructions, your environment profile, and the file
contents the agents read from your repos. Review your provider's data terms
with that in mind.

## Troubleshooting

- **Agents fail with an LLM error** · the provider rejected the key. Check
  the key, that the account has credit, and (OpenRouter) that the model name
  starts with `anthropic/`. Then save it again.
- **Agents fail with a configuration error** · no key is configured, or the
  runner has not collected it yet. Check **Runners** and your runner's logs.
  A saved key waits two hours for a runner; after that, save it again.
