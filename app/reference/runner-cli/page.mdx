## Rule authoring

- `trustacks rule new` · scaffold a new customer-overlay rule
- `trustacks rule test` · run the rule's tests
- `trustacks rule lint` · prove the rule ratchets stricter, never looser
- `trustacks rule sign` · sign the rule with your overlay key
