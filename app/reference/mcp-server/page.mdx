# MCP server

<Callout type="info">
  **Draft.** This page is a skeleton.
</Callout>

TruStacks reaches every external system through the Model Context Protocol.
The runner hosts a TruStacks-authored MCP server and consumes MCP servers
your stack already provides (Datadog, Jira, ServiceNow, Snyk, Splunk).

## Why MCP

- The agent runtime stays ignorant of *which* tools you use
- The Environment Profile drives *what* gets connected
- Every agent gets a uniform shape for tool calls
