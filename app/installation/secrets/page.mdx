# Credentials and secrets

<Callout type="info">
  **Draft.** This page is a skeleton.
</Callout>

TruStacks never holds production credentials. The runner needs a tightly
scoped set of tokens to read your application repositories and open pull
requests against your platform repository.

## Required credentials

- A Git App or service account scoped to the repositories the crew should
  observe. Read on application repos. Pull-request write on the platform
  repo's feature branches and the overlay repo's feature branches.
- An LLM provider key, if you are not on the TruStacks-managed default.

## Optional credentials

- Container registry pull credentials (for image scanning)
- Scanner API tokens (Snyk, Sonarqube, etc.)
- Observability tokens (Datadog, New Relic, etc.)
