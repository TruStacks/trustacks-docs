# TruStacks Docs

TruStacks is a crew of AI agents that proposes software-delivery changes (CI
workflows, Helm or Kustomize config, ArgoCD Applications) as pull requests in
your platform repo. Every proposal is checked against a signed policy before
the pull request opens, and a human on your team merges it.

**Agents propose. Policy decides. Humans approve.**

This site is the technical reference. For positioning and pricing, head to
[trustacks.com](https://trustacks.com).

## The unit you adopt: an Application

You use TruStacks one **Application** at a time. An Application is:

- one or more **service repos**: application code the crew reads; and
- one **platform repo**: your GitOps repo, where the crew opens pull requests
  with the CI workflow, deployment config, and ArgoCD Applications for those
  services.

Each service repo belongs to exactly one Application. TruStacks never writes generated
files into your service repos. The one file you add there yourself is a small
CI caller workflow, once per service.

## How the rules fit together

```text
┌──────────────────────────────────────────────────────────────────┐
│  Your overlay rules (optional)                                   │
│  Can only add denials; can never loosen the constitution.        │
├──────────────────────────────────────────────────────────────────┤
│  Specialists                                                     │
│  Baseline Security (included) · SOC2 Specialist Pack             │
├──────────────────────────────────────────────────────────────────┤
│  Constitution (signed, public, every tier)                       │
│  The rules every proposal must pass before a PR opens.           │
└──────────────────────────────────────────────────────────────────┘
```

The constitution is published from the public
<a href="https://github.com/TruStacks/trustacks-policy" target="_blank" rel="noopener noreferrer">trustacks-policy</a>
repo and signed, so you can read every rule and verify the bundle your runner
evaluates. The specialists review your setup during gap analyses. Overlay
rules can be drafted in the app today; delivering your own signed rules to a
hosted runner is not available yet.

Your GitOps controller deploys merged pull requests the way it always has.
